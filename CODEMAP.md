# CODEMAP

Where things live in cinewright. Rules are in [AGENTS.md](AGENTS.md); the plan is [ai-docs/plans/PLAN.md](ai-docs/plans/PLAN.md).

| Path | What | Edit here? |
|---|---|---|
| `.claude-plugin/marketplace.json` | lists the three plugins | yes |
| `plugins/<name>/.claude-plugin/plugin.json`, `plugins/<name>/plugin.json` | Claude manifest and Agent Plugins 1.0 manifest per plugin | yes |
| `plugins/<plugin>/skills/<skill>/SKILL.md` | router to the skill's references; 80 lines or fewer. Core (`plugins/cinewright`): cinewright, shots, continuity, genvideo, qc. Craft (`plugins/cinewright-craft`): script, design, movement, camera, history, edit, finish, sound, voice | yes |
| `plugins/<plugin>/skills/<skill>/references/*.md` | one knowledge entry per file (frontmatter per `shared/schemas/entry.schema.json`) | yes, except copies |
| `.../references/INDEX.md` | generated by `cine.py build` / `kb index` | no |
| `.../needs.json` | which `shared/` files `build` copies into the skill | yes |
| `.../scripts/cine.py`, `.../scripts/schemas/`, copied vocab entries | copies from `shared/`, with a `copied from ... sha256:` header | no |
| `.../RESEARCH.md`, `CHANGELOG.md`, `LEARNINGS.md`, `TESTS.md`, `evergreen.json`, `evals/evals.json`, `MAINTENANCE.md` | evergreen companions | yes |
| `shared/vocab/` | shot sizes, moves, angles, screen-direction phrases, the thirty-degree rule (shots and continuity), aspect ratios, lens and lighting terms (camera and history), cut terms (edit and sound), loudness targets (sound and qc; the `qc loud` presets mirror it), failure codes (`failures-*.md`, parsed by `qc rubric`) | yes, then build |
| `shared/schemas/` | entry, model card, shot card, six bibles (style, characters, props, locations, scenes, voices; props and voices optional), take record. Style carries the S4 look fields: `lighting`, `frame_aspect`, `lens_family`, `allowed_moves`, `history` | yes, then build |
| `shared/lib/cine.py` | runtime CLI shipped in every skill: kb, cards (new, validate, list, export), compile, continuity, qc (`loud --preset`, table `LOUD_PRESETS`), takes, voice (measure, ref, check: stdlib YIN pitch through ffmpeg) | yes, then build |
| `plugins/cinewright/skills/cinewright-genvideo/references/<model>.md` | one model card per model; its `## Compile` json block drives `compile` (fields in `shared/schemas/model-card.schema.json`) | yes |
| `plugins/cinewright/skills/cinewright-qc/SETUP.md`, `plugins/cinewright-craft/skills/cinewright-voice/SETUP.md` | ffmpeg and ffprobe needs (voice adds optional ComfyUI, Ollama, ElevenLabs key), read by `evergreen.py setup` | yes |
| `scripts/cine.py` | maintainer CLI: imports the runtime and adds `kb lint`, `budget`, `zip`, `build`, `--root` | yes |
| `tests/test_cine.py` | unittest suite, one or more tests per command | yes |
| `evals/run_evals.py` | headless eval harness for every skill's `evals/evals.json` (plan, run, report, regrade, rejudge, export-worth); `evals/inspect_run.py` prints one run; `evals/record_tests.py` writes the T- entries. Results stay outside the repo (default `<temp>/cinewright-evals`) | yes |
| `plugins/*/skills/*/evals/check_*.py` | stdlib outcome checkers a case names in `checks` (exit 0 only on a right result) | yes |
| `examples/three-shot/` | worked example: brief, script, design notes, bibles, cards, `takes.md` (the rendered parts, media outside the repo), `styles/` (a look tried with `--style`); `compiled/` must match a fresh compile (a test checks) | yes, then recompile |
| `.github/workflows/ci.yml` | manual-dispatch checks on a self-hosted runner while private | yes |
| `ai-docs/` | everlast doc set: log, HANDOFF, plans, research, decisions | yes (INDEX.md is generated) |

# cinewright-analyze references

Generated by `cine.py kb index`; do not hand-edit. Open one entry with `python scripts/cine.py kb show <slug> --section <name>` (sections: Rules, Numbers, Vocabulary, Pitfalls, Verify, Notes).

- `ai-video-tells`: How to judge whether a video is AI-generated: provenance first, then a frame checklist (text, hands, permanence, physics, boiling, identity drift, light), answered in confidence bands with timestamps.
- `camera-moves`: The camera-move tokens a shot card allows (one per card), what each does physically, and the prompt words each compiles to.
- `extraction-routes`: Which tool extracts what from a video: ffmpeg or PySceneDetect for cuts, frames plus a vision model for content, Gemini for video with audio and YouTube links, Whisper for dialogue.
- `film-notation`: The notation file that records a video shot by shot and set by set in character heights, how to fill it, and how it maps onto shot cards and level briefs.
- `room-scale`: Measure a set's width, height, floor depth and camera height in character heights from one frame, with the measure-file fields and the traps that made a rebuilt room 2.5 times too wide.
- `shot-sizes`: The eight shot-size tokens cards use (EWS to ECU), what each frames, the order used for size steps, and the prompt words each compiles to.

# cinewright-qc references

Generated by `cine.py kb index`; do not hand-edit. Open one entry with `python scripts/cine.py kb show <slug> --section <name>` (sections: Rules, Numbers, Vocabulary, Pitfalls, Verify, Notes).

- `camera-moves`: The camera-move tokens a shot card allows (one per card), what each does physically, and the prompt words each compiles to.
- `failures-motion`: Failure codes for rendered takes (action, opening, end state, anatomy, physics, text, dialogue, sound, seams, spec, loudness): symptom, cause, cheapest fix, rung, check.
- `failures-picture`: Failure codes for rendered takes (identity, wardrobe, props, direction, eyeline, light, look, camera): symptom, cause, cheapest fix, rung, check.
- `loudness-targets`: Delivery loudness targets checked 2026-10-04 (EBU R128 v4 and s2, ATSC A/85:2026, Netflix, Spotify) with tolerance, true peak, how each is measured, and the matching qc loud preset.
- `qc-loop`: How to judge a take against its card from a contact sheet, last frame and audio; verdict rules, frame sampling numbers, one change per reroll, three strikes.
- `shot-sizes`: The eight shot-size tokens cards use (EWS to ECU), what each frames, the order used for size steps, and the prompt words each compiles to.

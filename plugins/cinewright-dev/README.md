# cinewright-dev

Maintainer tools for the cinewright knowledge base: adding, verifying and retiring reference entries, and refreshing model cards when a video model changes.

This plugin has no skills yet; `cinewright-curate` arrives in a later release. It is listed in the cinewright marketplace for maintainers and is never submitted to plugin directories. People who only want to make films do not need it. Use the core `cinewright` plugin instead. License: MIT.

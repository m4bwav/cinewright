# cinewright-design references

Generated by `cine.py kb index`; do not hand-edit. Open one entry with `python scripts/cine.py kb show <slug> --section <name>` (sections: Rules, Numbers, Vocabulary, Pitfalls, Verify, Notes).

- `clean-references`: A reference image outranks the prompt, so every mark on it is copied into the video; paint out emblems, text and stray details before a reference goes into a shot.
- `color-script`: Three to five named colors, one named scheme, a scene color row (hue, brightness third, saturation, warmth) that moves with the story, taught meanings, successive contrast.
- `costume-arc`: Wardrobe that changes with the story, written as per-scene wardrobe strings in the character bible, with progressive damage and dirt tracked scene by scene.
- `lora-or-references`: When a trained character, prop or style LoRA beats reference images, which model to train first, a starting recipe, updating one with new data or a costume, and testing; video LoRAs come last.
- `prop-constants`: Give every prop that is held or seen close a fixed description in bibles/props.json; the compiler pastes it wherever a card holds the prop, and qc checks its look.
- `prop-sheets`: A hero prop gets its own reference sheet (alone, grey backdrop, three angles and a detail), one sheet per state; the compiler sends it with every shot that holds or features the prop.
- `turnaround-sheets`: Make each recurring character one turnaround sheet in a single image (front, three-quarter, back), then crop the views into separate reference files.
- `visual-structure`: Block's plan: story intensity 0-100 per scene, one line of point of view, and per component a constant, a progression or peaks; cards graph and grade measure --plan check it.
